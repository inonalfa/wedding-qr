# wedding-qr

עמוד קבוע לקוד QR שיודפס על הקנבס.

## הכתובת הקבועה

https://inonalfa.github.io/wedding-qr/

**לא משנים את הכתובת הזו אחרי שמדפיסים את הקוד.**

## איך משנים את היעד

1. פותחים את הקובץ [destination.json](destination.json).
2. בוחרים בעריכה (סמל העיפרון).
3. מחליפים את הערך של `url` בכתובת HTTPS הרצויה, לדוגמה:

```json
{
  "url": "https://example.com/our-wedding-dance"
}
```

4. שומרים את השינוי ב-Commit changes.
5. ממתינים לפרסום ב-GitHub Pages (לעיתים כמה דקות) וסורקים שוב לבדיקה.

כדי להציג שוב את העמוד הזמני, משאירים את `url` כמחרוזת ריקה: `""`.

## חשוב לדעת

- הקובץ `index.html` הוא עמוד מעבר. בעת ביקור בו הדפדפן קורא את `destination.json` ומעביר ליעד שהוגדר.
- אין צורך לייצר קוד QR חדש כשמשנים את הקישור.
- השירות אינו כרוך ברכישת דומיין, אבל ה-QR תלוי בכך שחשבון GitHub, המאגר הציבורי ו-GitHub Pages יישארו פעילים.
- אין לשמור בקובץ היעד קישור פרטי שמעניק גישה לתוכן רגיש, אם לא רוצים שכל סורק יוכל לצפות בו.
